# 智数学院算法集训队

公开网站：https://herkyherky.github.io/

管理后台：https://herkyherky.github.io/admin.html

GitHub Pages 提供静态页面；管理服务以服务端鉴权和独立数据库保存共享内容。管理员密码不写入公开仓库。

管理员登录后可修改预设主页文字与人数、管理方案、成员公开资料、每日训练及模拟赛榜单。页面结构和按钮固定。超级管理员还可以添加或删除普通管理员。每个账号均可验证当前密码并修改自己的密码，修改后全部旧会话失效。

访客只读。训练记录不再保存为浏览器本机草稿。后台保存后，公开网站刷新或重新获得焦点会加载最新数据；服务暂不可用时，页面显示初始静态内容并提示未取得最新记录。

`site-config.js` 为公开管理服务地址，`site-client.js` 同步固定文字、管理方案和训练数据。`admin.html` / `admin.js` / `admin-training.js` / `admin.css` 为后台界面。`team-data.json` 和内嵌数据为初始资料，后续后台数据库为实际数据来源。

训练时间：每周一至周四、周日 19:00–21:00。日常 AC 与比赛 AC 分开统计；每天训练总时长包含比赛，只在日报记录一次。未录入不视为零。纳新标准及原申请表下载保留。
