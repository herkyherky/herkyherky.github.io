一、总则与申请事项

（一）方案定位

本方案是ACM集训队整体管理方案，适用于全体正式队员和旁听队员，涵盖组织分工、队员管理、集训安排、考勤请假、考核机制、队伍动态规划、换届传承和教学流程等内容。大一正式队员晚自习豁免是本方案中的专项申请事项，不是全队管理边界。

（二）申请事项

恳请学院/学工批准：仅对经备案公示的大一正式队员，在固定时间、固定地点参加ACM集训的时段，办理同期晚自习请假/豁免考勤；其他人员、其他时段不适用。大二及以上队员无晚自习，正常参加集训，不涉及晚自习请假。旁听队员不享受晚自习豁免。

（三）核心原则

1. 全队统一管理。 正式队员、旁听队员均纳入队内考勤、训练和考核管理。
2. 大一专项豁免。 只有经指导老师审核、辅导员/学工备案并公示的大一正式队员，才具备晚自习豁免资格。
3. 限时、限地点、限时段。 豁免仅限与集训完全重叠的晚自习时段，不豁免课堂、实验、班会、年级大会、查寝、考试及其他集体活动；集训取消或提前结束，剩余时间按学院规定处理。
4. 集训不是放假，管理闭环。 全队执行队内考勤；大一豁免对象另执行专项签到台账，随时可查。
5. 动态管理、能进能出。 滚动选拔、动态淘汰；退出正式队或考核不达标，大一队员同步收回晚自习豁免资格。

二、组织管理与队内分工

设队长1名、副队长1名、学生负责人1名，对接指导老师赵宁社、辅导员/学工。全队实行分组管理、老带新、轮值出题与备案。

（一）岗位职责

1. 队长： 统筹全队训练和竞赛，负责训练计划、模拟赛组织、轮值出题与备案安排；对接指导老师，协调各组老带新；每月5日前会同学生负责人报送上月集训简报。
2. 副队长： 协助队长落实日常训练，负责全队训练考勤登记、大一正式队员晚自习豁免专项签到和台账归档；每周更新豁免名单；组织请假审批单收集和缺勤记录，交叉复核，避免自记自批。
3. 学生负责人： 负责对接辅导员/学工，报送大一豁免名单、出勤情况和每月简报；负责竞赛报名联络、竞赛成绩收集归档、承诺书和备案材料管理；协助队长处理对外事务。
4. 队长、副队长、学生负责人之间互相提醒、交叉复核；指导老师/学工可随机抽查台账。

（二）分组与老带新

1. 分组原则： 按算法方向、年级和水平混合编组，每组老中青搭配，避免强弱扎堆；每组由1名大二及以上或高年级正式队员担任带新负责人，负责本组训练、复盘、考勤提醒和新队员帮扶。带新负责人由老队员兼任，不单设岗位。
2. 老带新： 每组老队员带1-2名新队员，负责代码规范、训练任务答疑、模拟赛复盘和参赛经验传授；新队员跟组训练，纳入队内考勤和考核。分组每学期初调整一次，中期可微调。
3. 组内职责： 带新负责人组织本组训练和复盘，记录组员训练任务完成情况，向队长反馈进度；协助提醒大一正式队员专项签到，但不替代副队长记录。

（三）轮流承担竞赛出题、备案

1. 队长学期初排定轮值表，各组轮流承担内部赛/模拟赛出题、题解、测试数据和备案工作；出题组须提前提交题目和题解，经队长或指导老师审核后使用。
2. 备案内容： 题目、题解、测试数据、使用场次、参赛成绩、复盘记录；竞赛报名、获奖证书和成绩截图由学生负责人统一归档。
3. 轮值出题和备案质量计入该组及个人训练任务考核；无故不承担、拖延或题目质量差，按训练任务未完成记录，组内带新负责人负提醒责任。
4. 出题、备案台账与考勤台账分开存档，随时可查。

三、队员管理

1. 团队规模正式队员上限12人， 旁听队员名额根据招新、考核和梯队建设情况动态调整。
2. 队员分正式队员、旁听队员，全队均须遵守训练考勤和队内管理。只有备案公示的大一正式队员才有晚自习豁免资格；旁听队员不享受晚自习豁免。
3. 滚动选拔、动态淘汰：每年新生季招新，形成梯队；自律差、考核不达标者移出正式队，大一队员同步收回晚自习豁免。
4. 正式队员名单实行动态更新，新增、退出、暂停豁免均需报备并公示后生效，不追溯此前时段。
5. 新增大一正式队员须签署《晚自习豁免边界告知及承诺书》，并向班长/学习委员告知豁免仅限集训重叠时段。

四、集训时间、地点与内容

1. 时间（暂定）： 每周一至周四、周日19:00-21:00（2小时）。假期前一晚不训练；收假前一天照常训练。如遇课程、考试、学院统一安排或未返校，按学院安排优先并正常请假。每学期初发布训练日历，变更提前报备；考试周、课程设计周可调整并提前公示。
2. 地点： （待定，建议固定实验室/机房/活动室，并报备场地安全与用电责任）。
3. 内容： 日常训练任务、专题讲解、每周不少于一次模拟赛，目标冲击ICPC/CCPC,蓝桥杯、省赛等赛事奖项。
4. 安全提醒： 晚训结束结伴回寝，注意场地用电和人身安全。

五、考勤与请假

（一）全队训练考勤

全体正式队员、旁听队员均按队内训练考勤登记，执行签到/签退，台账存档。该考勤用于队内考核、淘汰和简报，不直接作为晚自习豁免依据。

（二）大一晚自习豁免专项签到

仅对申请晚自习豁免的大一正式队员执行：集训2小时，现场线下签到，建议“开始签到—每小时签到—结束签退”，专项台账存档，随时可查。专项签到与全队考勤可同表分栏，避免两套记录冲突。

（三）请假规则

1. 可请假（需证明、提前审批）： 生病（校医院证明）、学院统一必修安排、突发家事（凭证）。建议提前1个工作日提交；突发情况24小时内补证明。
2. 不予请假： 休闲、写作业、社团、兼职等个人事由。
3. 大一豁免对象请假获批后，同步在专项台账标注；请假后是否补训由队长安排，补训计入考核，无故不补训按缺勤处理。

（四）处罚与申诉

1. 全队队内考勤： 无故缺勤按队规处理，达到阈值暂停或取消正式队员资格；旁听队员按队内规则处理。
2. 大一晚自习豁免专项： 无故缺勤1次通报警告；累计2次暂停豁免1周；累计3次或连续2次取消本学期豁免并移出正式队。迟到/早退超15分钟按缺勤0.5次计，超30分钟按1次计。
3. 处理应记录、告知，允许24小时内申诉复核。
4. 每次集训后向辅导员/学工报送大一豁免对象出勤名单；集训取消或提前结束，及时通知队员按学院规定回晚自习。
5. 队长，副队长，学生负责人额外加成考勤分。

六、考核机制

每月综合考核全队，考核结果与正式队员资格、大一正式队员晚自习豁免资格挂钩。建议权重：

考勤30% + 训练任务30% + 模拟赛20% + 竞赛成绩20%。

1. 考勤： 全队训练考勤；大一豁免对象另看专项签到。无故缺勤按第五部分处理，由副队长记录、队长复核、学生负责人报备。
2. 训练任务： 日常任务完成度、代码质量、复盘参与、老带新帮扶情况；轮值出题、题解、测试数据和备案质量计入训练任务分，由队长审核记录。
3. 模拟赛： 每周不少于1次模拟队伍比赛，按参与度、解题数、排名和复盘质量计分。
4. 竞赛成绩： 蓝桥杯、省赛、校赛及队内正式竞赛成绩计入考核；个人赛按个人成绩，团队赛按贡献和团队成绩综合评定。无正式竞赛的月份，由内部模拟赛/月赛成绩替代竞赛成绩项。
5. 竞赛获奖、出题备案质量高、老带新成效明显的，可在训练任务或竞赛成绩项中加分；加分须有记录、可复核。
6. 考核不达标的正式队员移出正式队；大一正式队员同步收回晚自习豁免。

七、学风建设

（一）建设目标

坚持“以赛促学、以练促思、学赛兼顾”的原则，把ACM集训队建设成为学院优良学风建设的示范团队。以算法竞赛为抓手，带动程序设计、数据结构、算法分析等专业课程学习，营造勤学善思、互帮互学、诚实守信的学习氛围。

（二）学业优先与时间管理

1. 坚持专业课程学习与竞赛训练并重。队员须正常参加课堂教学、实验、考试和学院规定的集体活动；晚自习豁免仅用于规定时段内的集训，不等于免除课程学习义务。
2. 鼓励队员合理制定学期学习计划，统筹课程作业、考试复习与竞赛训练。课程冲突时以教学安排为先，不得以集训名义无故旷课、迟交作业或缺席考试。
3. 考试周前按本方案缩减并停止统一集训，优先保障课程复习；如队员出现明显学业困难，由带新负责人协助制定学习与补训安排，并报指导老师协调。

（三）学习互助与示范引领

1. 依托分组管理和老带新机制，开展算法专题讲解、代码交流、错题复盘与学习经验分享，鼓励高年级队员帮助低年级队员夯实基础。
2. 定期分享专业课程与竞赛之间的知识联系，推动训练成果反哺课程学习；鼓励队员在班级、学院开展公开讲题或学习交流活动，带动更多同学参与自主学习。
3. 倡导独立思考、主动提问、及时总结的学习习惯，建设队内共享题库、题解和学习资料库，形成可持续的学习资源积累。

（四）学术诚信与良好风气

1. 严格遵守考试纪律和各类竞赛规则，杜绝考试作弊、竞赛代打、抄袭代码、冒用成果及伪造训练记录等行为。
2. 日常训练鼓励讨论思路，但个人独立完成的任务须如实标注参考来源及合作情况；正式比赛严格执行赛事关于交流和工具使用的要求。
3. 树立重过程、重能力、重团队协作的评价导向，不唯排名和奖项，不以训练强度替代学习质量。

（五）监督反馈与成果展示

1. 将学风表现作为队员日常综合评价的参考内容，重点关注课堂纪律、学业与集训协调、学习互助及诚信表现；涉及学业情况的反馈应尊重个人隐私，不公开传播个人成绩。
2. 每学期结合训练总结开展一次学风建设评估，梳理学习交流活动、队员成长与竞赛成果，由队长汇总、指导老师审核，纳入集训队工作总结。
3. 对学业与竞赛协调良好、积极帮扶同学、公开分享学习成果的队员予以表扬；对违反学术诚信或严重影响正常教学秩序的行为，按校纪校规及队内制度处理。

八、长效机制

每年新生季招新，老生带新人维持队伍。每学期初更新备案名单，期中复核。若大一队员频繁缺勤、管理失控，由指导老师提出、辅导员/学工同意后，暂停全队大一队员晚自习豁免，限期整改，验收后恢复。暂停全队豁免须履行审批程序，不能个人随意决定。

九、队伍动态规划（中后期调整补充）

现有方案为前期规划。前期队员普遍没有算法基础，招新以建立队伍基础为主；中后期逐步提高要求。具体如下：

（一）前期

1. 队员普遍没有算法基础，招新以建立队伍基础为目的。
2. 主要面向有意向学习算法、对竞赛有兴趣的学生。
3. 招新考核以适应建队基础为主，不设过高门槛。

（二）中期

1. 积累队伍名气，扩大队伍规模。
2. 随报名人数增加，逐步完善梯队。
3. 招新加入难度适中的考核，初步筛选学习能力、训练态度和算法基础。
4. 以蓝桥杯、ACM等赛事取得更好成绩为目标，争取奖项突破，提升队伍竞赛水平。
5. 视队伍规模和训练需要，探索寒暑假集训；具体时间、地点、内容、安全预案和审批程序，与指导老师、辅导员/学工协调后确定。

（三）后期

1. 队伍运行较为完备。
2. 招新考核难度加大，重点筛选更优秀、更具竞赛潜力的队员。
3. 建立完备的招新考核机制，用于队员选拔与淘汰。
4. 定期由指导老师带队与其他高校交流。
5. 邀请毕业生在大群分享工作经验等。
6. 条件成熟时，寒暑假集训逐步常态化，纳入年度训练计划；由指导老师带队或按学院要求审批，明确安全预案和训练目标。

其他考核机制正文不变，后期重点推动完备招新考核落地。

十、换届与传承机制

（一）换届制度

1. 换届周期： 每学年组织一次换届，原则上在学年末完成；遇特殊情况可提前或延期，报指导老师同意。
2. 换届岗位： 队长、副队长、学生负责人。各组带新负责人随分组调整产生，由高年级正式队员兼任，不单设岗位。
3. 人选条件： 正式队员，训练考勤和考核达标，有责任心，具备一定组织和竞赛经验；队长原则上由高年级正式队员担任。
4. 产生程序： 个人自荐或队员推荐，指导老师审核，辅导员/学工备案，队内公示后生效。
5. 交接内容： 全队名单、大一豁免名单、考勤台账、考核记录、竞赛成绩、轮值出题备案、题库题解测试数据、训练日历、毕业生联络方式、经费与场地事项等，形成书面交接清单。
6. 过渡期： 新老负责人设1-2周过渡期，老负责人带新负责人熟悉台账和报备流程，避免断档。
7. 换届不影响在队队员的大一晚自习豁免资格，豁免资格仅随正式队员资格和考核结果动态调整。

（二）竞赛风气与传承保障

1. 以赛促练： 每周不少于一次模拟赛，定期组织内部赛、月赛，积极组织参加蓝桥杯、省赛、校赛等，保持常态化竞赛节奏。
2. 轮值出题备案： 各组轮流承担出题、题解、测试数据和备案，队长审核质量并计入训练任务考核，防止只参赛不建设。
3. 竞赛成绩计入考核： 竞赛成绩按个人赛、团队赛和参赛层级计入月度考核，与正式队员资格、大一豁免资格挂钩。
4. 老带新绑定： 每组高年级正式队员带1-2名新队员，负责代码规范、训练答疑、模拟赛复盘和参赛经验传授；老带新成效纳入训练任务评价。
5. 动态淘汰： 正式队员考核不达标移出正式队，大一队员同步收回晚自习豁免；旁听队员表现优秀可晋升，保持队伍竞争性。
6. 资料传承： 题库、题解、测试数据、备案材料、竞赛成绩、复盘记录和培训资料统一归档，形成可传承的资料库，换届时逐项交接。
7. 毕业生反哺： 建立毕业生大群，邀请毕业生分享工作经验、参赛经验、就业保研等；学生负责人收集分享记录，作为队伍传承材料，不纳入集训考勤。
8. 表彰与公示： 对竞赛获奖、出题备案质量高、老带新成效明显的队员和小组进行队内表彰或公示，形成正向激励。
9. 定期评估： 每学年结合换届评估竞赛风气、梯队建设、老带新成效和资料传承情况，问题集中整改，确保队伍长期稳定传承。


十一、队内教学流程（本学期特殊安排）

本学期后半段以“过一遍算法基础”为主线，从第8周开始，至考试周前停止集训。考试周前集训停止后，队员以复习考试为主；教学进度不追求全覆盖，优先保证零基础队员打牢基础。

（一）总体安排

1. 第8周： 摸底测试，了解队员基础，区分零基础与有基础队员，分组老带新结对。
2. 第8周至考试周前： 按“基础语法—基础数据结构—基础算法—综合模拟”顺序推进，每周一个主题，配训练任务和周末模拟赛。
3. 考试周前1-2周： 停止新内容，进行综合模拟和验收；随后停止集训，队员转入考试复习。
4. 有基础队员在完成基础任务后，增加提高题和竞赛题；零基础队员按基础进度要求推进，不盲目拔高。

（二）零基础队员进度要求

1. 集训第4周末： 能独立完成基础语法题，掌握输入输出、变量、分支、循环、数组、字符串、函数等。
2. 集训第8周末： 掌握基础数据结构，能使用排序、二分、栈、队列、简单递归等解决入门题。
3. 集训第12周末： 掌握基础算法入门，包括简单枚举、模拟、贪心、简单动态规划等，能完成模拟赛中的简单题。
4. 考试周前验收： 能独立完成入门级综合题和模拟赛简单题，具备继续参加集训的基础；未达标者由带新负责人帮扶，并在下学期初补测。

（三）教学组织

1. 每周训练按“主题讲解—任务练习—模拟赛—复盘”进行；队长统筹教学计划，各组带新负责人负责本组答疑和进度跟踪。
2. 轮值出题备案与教学主题结合，出题组承担对应主题的练习题和模拟赛题。
3. 教学考勤纳入全队考勤；大一正式队员晚自习豁免专项签到不变。
4. 考试周前停止集训，不安排新任务；考试周以课程复习考试为主，集训队不组织统一训练。

（四）验收与调整

考试周前由队长组织一次教学验收，记录零基础队员达标情况；未达标队员列入下学期初帮扶名单。下学期根据验收结果调整教学进度和招新考核难度。
